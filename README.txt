INNASOL WEBSITE - SETUP NOTES

Upload everything in this folder to the root of your hosting (index.html must sit at the top level).

BEFORE GOING LIVE, open index.html and change:
1. PHONE and EMAIL  (search for: EDIT YOUR CONTACT DETAILS HERE)
2. WA  = WhatsApp number, country code first, no + or spaces, e.g. 447123456789
3. YOURDOMAIN.co.uk  (two og:image / twitter:image tags near the top) -> her real domain
4. Gallery: replace each <div class="ph"> block (search: Replace each .ph block) with <img> or <video>
